# HR HUB — Dokumentasi

Panduan pengguna untuk tim HR & Talent Acquisition MRA Group. Dokumentasi teknis untuk developer ada di [`CLAUDE.md`](../CLAUDE.md).

## Panduan pengguna (`guides/`)

Urutan di bawah mengikuti alur rekrutmen: dari lowongan dibuka sampai karyawan baru selesai onboarding.

| Panduan | Untuk | Isi |
|---|---|---|
| [Recruitment Dashboard](guides/dashboard/README.md) | Semua pengguna | Angka utama, funnel, bottleneck, Action Center, laporan Excel, lonceng pengingat |
| [Manpower Request](guides/manpower-request/README.md) | Hiring Manager, TA Lead, HR Director | Mengajukan, menyetujui, membuka lowongan, dan memantau permintaan rekrutmen |
| [Manage ATS Jobs](guides/job-management/README.md) | TA Lead, HR Director | Membuat lowongan, PT, Hiring Manager, kata kunci ATS, visibilitas gaji, menutup lowongan |
| [Applicant Pipeline](guides/applicant-pipeline/README.md) | Recruiter, TA Lead, Hiring Manager | Claim kandidat, memindahkan tahap, syarat tiap tahap, persetujuan, detail kandidat |
| [Database & Profiles](guides/candidate-database/README.md) | Recruiter, TA Lead, Hiring Manager | Mencari kandidat, profil ATS, riwayat lamaran, profil ganda |
| [Talent Pool Matching](guides/talent-pool/README.md) | Recruiter, TA Lead | Mencari kandidat lama yang cocok untuk lowongan baru dan memasukkannya ke pipeline |
| [Interview Calendar](guides/interview-calendar/README.md) | Recruiter, TA Lead, Hiring Manager | Jadwal interview, bentrok jadwal, undangan Google Calendar / WhatsApp, jadwal ulang |
| [Offer Letters](guides/offer-letters/README.md) | Recruiter, TA Lead | Membuat surat penawaran PDF, mengirim, mencatat jawaban kandidat |
| [New Employees](guides/new-employees/README.md) | Recruiter, TA Lead, HR Director | Mendaftarkan karyawan, pengumuman, Recruitment Journey, kirim ke Talenta |
| [Onboarding](guides/onboarding/README.md) | HR, TA, Hiring Manager | Checklist karyawan baru per fase dan tim, masa percobaan |

Setiap panduan ada di foldernya sendiri: `README.md` + folder `images/` berisi screenshot.

**Versi Word:** semua panduan di atas dapat digabung menjadi satu manual Word (`docs/HR-HUB-Panduan-Pengguna.docx`, lengkap dengan sampul, daftar isi, dan bab Pendahuluan) dengan generator di [`tools/`](tools/README.md). File Word/PDF tidak di-commit. Buat ulang setiap kali panduan berubah.

Menu administrasi (Users & Access, Companies (PT), Templates & Bulk Import, TA Team Performance, Team Activity Log, Announcements) belum punya panduan tersendiri.
